`/ghpr` has an **Orgs** tab, before Settings, to choose which orgs' pull requests show, everywhere: exclude the chosen orgs, or include only theirs. It lists every org with an open pull request, and your teams' orgs, with counts, to choose from and search. The other tabs say how many pull requests it hides.
